# LinkedIn Auto-Posting Workflow (n8n)An n8n workflow that prepares LinkedIn content from Google Sheets, generates post text with an OpenRouter chat model, optionally generates an image with Cloudflare Workers AI, publishes the post to LinkedIn, and records the result back in Google Sheets.## Features* Reads a pending post task from Google Sheets.* Generates professional LinkedIn post copy with an OpenRouter chat model.* Uses a prompt from the spreadsheet to guide the generated text.* Can generate an image using Cloudflare Workers AI (`flux-1-schnell`).* Supports LinkedIn posts with an image or text only.* Updates the spreadsheet with the generated output, completion status, and LinkedIn post reference.* Includes a manual trigger for testing; a schedule trigger is also present but disabled in the exported workflow.## Workflow overview1. **Read task:** Selects a row whose `Status` is `Pending`.2. **Generate image:** Sends the row's `Image Instructions` to Cloudflare Workers AI and converts the returned image data into a file.3. **Store image:** Uploads the image to Google Drive and writes its link to the spreadsheet.4. **Generate post copy:** Sends `Post Description` and `Text Instructions` to the OpenRouter chat model.5. **Choose publishing path:** Checks whether an `Image link` is present.   * If present, downloads the image and publishes an image post.   * If absent, publishes a text-only post.6. **Record result:** Updates the matching spreadsheet row with the status, generated text, and LinkedIn post reference.The exported workflow is a starting point and may need adjustments to match your Google Drive sharing settings, spreadsheet layout, LinkedIn account configuration, and current n8n node versions.## Requirements* An n8n instance with the nodes used in this workflow available.* A Google account with access to Google Sheets and Google Drive.* A LinkedIn account authorized for posting through n8n.* An OpenRouter API account and API credential.* A Cloudflare account with access to Workers AI and an API token permitted to call the selected model.## Google Sheets structureCreate a sheet with these column headers (spelling and capitalization matter because the workflow references them by name):|Column|Purpose||-|-||`Post Description`|Topic or brief for the LinkedIn post; also used when naming the generated image file.||`Status`|Set to `Pending` for a row waiting to be processed.||`Image Instructions`|Prompt describing the image to generate.||`Image link`|Google Drive link containing the image for the post.||`Text Instructions`|guidance for the AI-generated post.||`Output`|Generated LinkedIn post text.||`Post Link`|Field for the resulting LinkedIn post reference/URN.|## Setup1. **Import the workflow**   * In n8n, import `LinkedIn-Auto-Posting-Bot.json`.2. **Configure Google Sheets and Google Drive**   * Create or select your spreadsheet and destination Drive folder.   * Set the correct spreadsheet ID, sheet/tab, and Drive folder in the relevant nodes.   * Reconnect your own Google Sheets and Google Drive credentials.   * Ensure the account can read and update the sheet and upload/download files from the selected folder.3. **Configure Cloudflare Workers AI**   * Set your Cloudflare account ID in the HTTP Request node URL.   * Add your API token using a secure credential or environment variable approach supported by your n8n setup. Do not commit a real token in the workflow JSON.   * Confirm the token has the permissions required to invoke Workers AI.4. **Configure OpenRouter**   * Add your own OpenRouter credential to the OpenRouter Chat Model node.   * Select a model available to your account and review its limits and pricing/free-tier conditions.5. **Configure LinkedIn**   * Connect your own LinkedIn OAuth credential to both LinkedIn publishing nodes.   * Set the appropriate LinkedIn person/profile identifier in both nodes.   * Confirm that your LinkedIn app and account have the permissions required for the selected publishing operation.6. **Review and test**   * Verify all placeholders have been replaced in n8n, not in the public repository.   * Start with one test row marked `Pending` and check each node's output.   * Confirm the image link is accessible to the Google Drive download node and that the resulting post is correct before enabling automation.   * The `Schedule Trigger` is disabled in this export. Enable and configure it only after the manual test succeeds.## Limitations and notes* The workflow relies on the structure and column names of the configured spreadsheet.* Image generation, file permissions, LinkedIn API access, and model availability depend on the external services and your account permissions.* The workflow's generated post text is limited by the prompt instructions; review generated content before using it in a production publishing process.* This repository provides the workflow export and setup guidance, not hosted services or API credentials.
